# skill

This is where `SKILL.md` will live — the discovery interview an AI agent
runs to scaffold a Power Platform project using the templates and scripts
in this repo.

Per [ADR-0001](../docs/adr/ADR-0001-estructura-modular-power-platform.md),
the interview only needs one real branching question ("does the project use
Power BI?"); everything else (Canvas App, Power Automate, or both) is
resolved by asking which components the project has, not which template to
load.

Currently a placeholder — the full `SKILL.md` is written in a later step.
