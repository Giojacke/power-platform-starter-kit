# templates/dataverse

Scaffolds for the **Dataverse module**: unpacked Solution structure, a
sample PCF component, and connection reference templates.

This module covers Canvas Apps, Power Automate flows, or both combined —
they are not separate templates, just optional subfolders of the same
Solution-based tree. See
[ADR-0001](../../docs/adr/ADR-0001-estructura-modular-power-platform.md)
for why this module is not split by app type.

Currently empty — scaffolds will be added incrementally.
