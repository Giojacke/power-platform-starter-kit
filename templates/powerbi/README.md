# templates/powerbi

Scaffolds for the **Power BI / Fabric module**: PBIP project structure
(`<Report>.Report/` and `<Report>.SemanticModel/`).

This module is independent of the Dataverse module — no shared folders, no
shared pipeline. It uses its own versioning mechanism (PBIP + Fabric Git
Integration) rather than `pac` or Azure DevOps Power Platform pipelines. See
[ADR-0001](../../docs/adr/ADR-0001-estructura-modular-power-platform.md)
for the full reasoning.

Currently empty — scaffolds will be added incrementally.
